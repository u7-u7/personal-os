# Demonstration script

1. Start the stack following the README. Open `/dashboard`; register an account with a unique email and a password of at least ten characters. Empty state is expected.
2. In Tasks create “Review PersonalOS architecture”, high priority, with a real deadline. Complete it; refresh and confirm persistence.
3. In Memory add a real preference as pending. Confirm it; edit its source/content; verify edits require confirmation. Request deletion and approve in Activity.
4. In Calendar create a local event. Attempt an overlap and show the conflict error. Google remains unconnected until OAuth credentials and consent exist.
5. In Settings select the DeepSeek preset and save a real API key. Keys remain on the server. Chat: “Create a task to review my priorities tomorrow and propose a preference that I work best in the morning.” Inspect tools, resulting task and pending memory.
6. Generate a briefing based on the actual data. Explain that without a model key this operation returns an error instead of a sample briefing.
7. Create an automation. Inspect schedule, pause/resume and execution history. Start the independent Worker. Demonstrate timeout/unknown-outcome behavior using controlled test fixtures, identified as fixtures.
8. Review connections and approval permissions. Only demonstrate MCP with an explicitly controlled and allowlisted server. Never claim a disconnected integration works.
9. Export your account's data. Confirm the export excludes credentials. Show dark mode and a narrow viewport.
10. Close with the verification report, open PR and remaining external authorization gates.
